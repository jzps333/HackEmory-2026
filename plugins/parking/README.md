# Parking helper

Operates the real parking site in the locked-down browser (ParkMobile with your saved sign-in, or
the Dogwood demo app): zone, vehicle, hours, then it stops on the confirm screen and reads you the
total. It never taps Pay or Start parking.

- **Runs on:** the locked-down VM.
- **Tools:** speak, screen, safe browser, parking (verified plugins only).
